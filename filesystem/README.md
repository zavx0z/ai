# Filesystem

Владеет доступом к явно зарегистрированным директориям. Не зависит от UI,
запущенного Bun-процесса, Git или браузера. Контекст создаётся функцией
`createFilesystem` и передаётся инструментам явно.

Публичные инструменты: `roots`, `open`, `list`, `stat`, `read`, `read-many`,
`write`, `create`, `apply-patch`, `mkdir`, `remove`, `rename`.
Состав находится в `package.json`; вход, выход, примеры и ограничения — у
каждого инструмента в `contract/`, TSDoc `index.ts` и `spec/`.

`read` использует байтовые диапазоны; для двоичных данных и границ внутри
UTF-8 символа используйте `base64`. `contentHash` появляется только при чтении
целого файла. `read-many` ограничивает и отдельный файл, и сумму прочитанных байтов.
`list` постепенно читает каталог; усечённая выборка не является пагинацией.

`write` заменяет существующий обычный файл через временный файл и rename,
сохраняя permission bits. Inode, mtime и свойства старого inode могут измениться.
`create` использует исключительное создание. Родительские директории не создаются
неявно, кроме явно разрешённого `createParents` и добавления файлов через patch.

Чтения идемпотентны при неизменных данных. Повтор `create`, `rename` или `remove`
после успеха может завершиться конфликтом или NOT_FOUND. `mkdir` с `recursive:true`
допускает повтор и возвращает `created:false`. Повтор `write` без expectedHash
сохраняет содержимое, но не inode/mtime. Patch не следует повторять вслепую.

Patch поддерживает `*** Begin Patch`, `*** Add File`, `*** Update File`,
`*** Delete File`, `*** Move to`, hunks `@@`, точные anchors `@@ text`
и `*** End of File`. Неоднозначное совпадение, fuzzy matching и повторные
операции одного пути отклоняются. Сохраняются CRLF и отсутствие финального
перевода строки у обновляемого файла; смешанные окончания строк отклоняются.
`dryRun:true` выполняет планирование без изменения файлов. Предварительные
ошибки не пишут файлы. Ошибка ОС после начала применения может оставить часть
изменений и возвращается как PARTIAL_FAILURE с перечнем завершённых операций.

Файловая запись никогда не выполняет debugger remap/replay. Этот составной
сценарий по-прежнему принадлежит Interpreter и не эмулируется данным пакетом.
