# Git

`status` читает ограниченный porcelain-v1 вывод Git выбранного файлового корня.
Он не требует UI selector и не использует shell. Путь checkout разрешается тем
же файловым контекстом, что и другие инструменты. В корне должна находиться
собственная `.git`; поиск репозитория в предках не разрешён.

Параметры и результат находятся в `status/contract/`, проверяемые примеры —
в `status/spec/scenario.spec.ts`. Имена с пробелами и переводами строк разбираются
через NUL-разделители; переименование содержит текущий и исходный путь.

Git получает фиксированные аргументы, отключённый fsmonitor и необязательные
блокировки. Его вывод ограничен 1 MiB, выполнение — 10 секундами.
Переполнение или timeout — ошибка, не успешный усечённый stdout. `maxEntries`
может ограничить уже корректно полученный результат с `truncated:true`.

`log`, `diff`, `show`, `blame`, изменение индекса и создание коммитов пока
не реализованы. Этот пакет не выдаёт их за перенесённые возможности Interpreter.
