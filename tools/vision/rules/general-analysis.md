### 📏 **Правило: Общий анализ интерфейса**

**Условие применения**: Пользователь загружает изображение интерфейса *без указания конкретных элементов для поиска*.

#### 🔹 **Требования к анализу**

1. **Идентификация всех элементов**:
   — Обнаружить *все* интерактивные и статические UI-компоненты (кнопки, поля ввода, текст, иконки и т.д.).
   — Исключить декоративные элементы (тени, градиенты, разделители без функционала).

2. **Классификация и именование**:

   | Тип элемента       | Правила именования                  | Примеры                     |
   |--------------------|-----------------------------------|----------------------------|
   | `button`           | Действие + «_button»               | `send_button`, `copy_button` |
   | `text_input`       | Назначение + «_input»/«_field»     | `search_input`, `message_field` |
   | `dropdown`         | Контекст + «_toggle»/«_selector»   | `language_selector`        |
   | `text`             | Роль + «_text»                     | `footer_text`, `title_text` |
   | `image_button`     | Функция + «_logo»/«_icon»          | `user_avatar`, `app_logo`  |

3. **Позиционирование**:
   — Координаты `(x_min, y_min, x_max, y_max)` нормализованы в диапазоне `[0.0, 1.0]`, где:
     - `(0.0, 0.0)` = верхний левый угол изображения,
     - `(1.0, 1.0)` = нижний правый угол изображения.
   — Значения округляются до **двух знаков после запятой** (например, `x_min: 0.15`, `y_max: 0.87`).

4. **Формат вывода**:

   ```json
   {
     "mode": "full_analysis",
     "interface_elements": [
       {
         "name": "string",
         "type": "enum",
         "position": { "x_min": float, "y_min": float, "x_max": float, "y_max": float }
       }
     ]
   }
   ```
