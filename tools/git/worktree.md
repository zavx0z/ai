# Основные команды

`git worktree add <путь> <ветка>` — создает новую рабочую директорию по указанному пути и переключает её на выбранную ветку.
`git worktree add -b <новая-ветка> <путь> <базовая-ветка>` — создает новую ветку и рабочую директорию для неё (если ветка ещё не существует).
`git worktree list` — выводит список всех активных рабочих деревьев и их пути.
`git worktree remove <путь>` — безопасно удаляет рабочее дерево, когда оно больше не нужно.
`git worktree prune` — очищает информацию о рабочих деревьях, которые были удалены вручную (через файловую систему).
