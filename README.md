# AI Assistant Tools 🛠️

Набор инструментов для AI-ассистентов (ChatGPT, Claude, Gemini и других) для улучшения работы с кодом и проектами.

## 📦 Основные инструменты

### 🔧 **Инструменты для работы с кодом**

| Инструмент | Назначение |
| ------------ | ------------ |
| **`actions/comment`** | Удаление и восстановление комментариев через AST. Поддерживает TypeScript/JavaScript файлы с сохранением метаданных |
| **`actions/fix`** | Инструмент для исправления TypeScript ошибок с точным указанием строк и контекста |
| **`actions/lines`** | Нумерация строк в файлах для точного указания позиций ошибок |
| **`actions/project`** | Сбор всей документации проекта в один файл с нумерацией строк |

### 🚀 **Генераторы и CLI**

| Инструмент | Назначение |
| ------------ | ------------ |
| **`generator/cli`** | Интерактивный файловый менеджер с PTY-поддержкой для навигации по проектам |
| **`generator/terminal`** | Документация по работе с PTY в Bun для создания интерактивных CLI |

## 🎯 Для чего это нужно AI-ассистентам?

### **Точная навигация по коду**

- Нумерация строк для точного указания ошибок
- Сбор всей документации проекта в один файл
- Интерактивный просмотр структуры проекта

### **Работа с комментариями**

- Удаление комментариев для анализа чистого кода
- Восстановление комментариев после анализа
- Статистика по комментариям в проекте

### **Интерактивные возможности**

- Навигация по файловой системе через терминал
- Выбор файлов для анализа
- Фильтрация по имени и типам файлов

## 🚀 Быстрый старт

```bash
# Клонирование репозитория
git clone <repository-url>
cd ai-tools

# Установка зависимостей
bun install

# Запуск инструментов
bun run actions/comment/cli.ts --help
bun run generator/cli/index.ts --help
```

## 📖 Использование с AI-ассистентами

### Для ChatGPT/Claude/Gemini

1. **Соберите документацию проекта**:

   ```bash
   bun run actions/project/collect-files.ts
   # Создаст ai-documentation.md со всем кодом и нумерацией строк
   ```

2. **Передайте файл ассистенту**:
   - Загрузите `ai-documentation.md` в контекст
   - Ассистент сможет точно указывать номера строк при анализе

3. **Работа с комментариями**:
   - Удалите комментарии для упрощения анализа
   - Восстановите их после внесения изменений

### Примеры команд

```bash
# Собрать всю документацию проекта
bun run actions/project/collect-files.ts

# Пронумеровать строки в файле
bun run actions/lines/cli.ts src/index.ts

# Удалить комментарии из файла
bun run actions/comment/cli.ts clean src/index.ts

# Запустить интерактивный файловый менеджер
bun run generator/cli/index.ts .
```
