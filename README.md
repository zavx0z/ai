# AI Tools

Repo `ai` входит в Project `zavx0z` как Git submodule.

Инструменты работы с назначенной хостом директорией: десять файловых операций
и Git status. Область закреплена за контекстом исполнения; агент задаёт
команду `{name, arguments}` с относительными путями.
`GET /tools` описывает только исполняемые инструменты; исходники и структурный
обход внутренних пакетов через потребительский API не выдаются.

- [Запуск, вызовы и проверки](DEVELOPMENT.md).
- [Результат миграции и исторические границы](MIGRATION.md).
- [Контекст рабочей области](workspace/index.ts).
- [Явные HTTP bindings](server/request/src/bindings.ts).

Репозиторий предоставляет инструменты. Цикл модели, чат и адаптеры моделей
не входят в его назначение. Storybook используется для проверки исходников,
без runtime-зависимости на него.
