# TypeScript Linter

Линтер для TypeScript кода, использующий TypeScript Compiler API для анализа и вывода ошибок в формате VSCode диагностики.

## Суть проекта

Инструмент для статического анализа TypeScript файлов через TypeScript Compiler API. Позволяет получать структурированные ошибки компиляции в формате, совместимом с VSCode, что удобно для интеграции в CI/CD и инструменты разработки.

## Текущий статус

✅ **Работает:** Базовая функциональность линтинга, поддержка tsconfig.json, обработка директорий, несколько форматов вывода  
🔄 **В процессе:** Оптимизация производительности для больших проектов  

## Ключевые идеи

### Архитектурные принципы

1. **Разделение ответственности:** Парсер, валидатор и форматтер работают независимо
2. **Гибкость конфигурации:** Поддержка tsconfig.json с автоматическим поиском или указанием пути
3. **Интеграционная готовность:** Вывод в формате VSCode диагностики для совместимости с существующими инструментами

### Особенности реализации

- Использует TypeScript Compiler Host для работы с виртуальной файловой системой
- Поддерживает strict режим поверх существующих конфигураций
- Фильтрация ошибок из node_modules
- Статистика по типам ошибок и файлам

### Технические нюансы

- Проект написан на TypeScript и использует Bun как среду выполнения
- Основная логика в `src/parser.ts` создаёт программу TypeScript и извлекает диагностику
- Форматтер преобразует ошибки в структурированный JSON, понятный редакторам кода
- CLI обрабатывает аргументы командной строки и управляет потоком выполнения

## Контекст для разработки

Проект задуман как модульный инструмент, где каждая часть может быть заменена или расширена. Текущая фокусировка на точности диагностики TypeScript, а не на кастомных правилах стиля кода.
