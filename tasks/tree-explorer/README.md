# 🌳 Tree Explorer - Интерактивный файловый менеджер для терминала

**Tree Explorer** - это мощный интерактивный CLI инструмент для навигации по файловой системе, созданный на Bun. Программа использует **сырой ввод/вывод терминала** для создания полноценного TUI (Text User Interface) интерфейса.

![Tree Explorer Interface](https://img.shields.io/badge/Platform-Linux%2FmacOS-blue) ![Bun Version](https://img.shields.io/badge/Bun-1.3.5%2B-ff69b4) ![Terminal API](https://img.shields.io/badge/API-Raw%20Terminal%20I%2FO-green)

## ✨ Особенности и возможности

### 🎯 Основные функции

- **🌳 Визуальная навигация** по файловой системе с иконками и подсветкой
- **🎯 Рекурсивный выбор** директорий одним нажатием
- **🚫 Система исключений** с поддержкой regex-паттернов (как в .gitignore)
- **🔍 Фильтрация** файлов по имени в реальном времени
- **👁️ Управление скрытыми файлами** (показать/скрыть)
- **🎨 Полная поддержка ANSI-цветов** и эмодзи
- **⌨️ Поддержка двух раскладок** (русская и английская)
- **📊 Показ размера файлов** и информации о симлинках
- **🔄 Динамическое изменение размера** терминала

### 🏗️ Техническая архитектура

Программа использует **прямой доступ к терминалу** без PTY API:

- `process.stdin.setRawMode(true)` - для обработки отдельных клавиш
- `process.stdout.write()` - для вывода в консоль
- ANSI escape codes - для управления курсором и цветами
- `process.stdout.on('resize')` - для адаптации к размеру окна

## 📦 Установка и запуск

### Требования

- [Bun](https://bun.sh/) версии 1.3.5 или выше
- Linux или macOS

### Конфигурация

Программа поддерживает YAML конфигурацию через файл `config.yaml` в корневой директории проекта.

Пример конфигурации:

```yaml
# Конфигурация Tree Explorer

# Файл для сохранения выбранных файлов в JSON формате
# Может быть абсолютным путем или относительным к текущей рабочей директории
outputFile: ./selected-files.json
```

Если файл `config.yaml` не найден или `outputFile` не указан, файлы будут сохраняться в текущей директории с уникальным именем (selected-files-<timestamp>.json).

### Быстрый старт

```bash
# 1. Скачайте или скопируйте файл index.ts
# 2. Дайте права на выполнение
chmod +x index.ts

# 3. Запустите программу
./index.ts                          # В текущей директории
./index.ts /path/to/directory       # В указанной директории
bun index.ts /path/to/directory     # Через bun
```

### Сборка в исполняемый файл

```bash
# Собрать в standalone бинарник
bun build --compile ./index.ts --outfile tree-explorer

# Запуск собранного бинарника
./tree-explorer /path/to/directory
```

## 🚀 Использование

### Синтаксис командной строки

```bash
# Базовый синтаксис
bun index.ts [ПУТЬ] [ОПЦИИ]

# Примеры
bun index.ts                        # Текущая директория
bun index.ts ~/projects             # Указанная директория
bun index.ts /Users/name/Documents  # Абсолютный путь
```

### Параметры командной строки

| Параметр | Короткая версия | Описание | Пример |
| -------- | -------------- | ---------- | -------- |
| `--exclude PATTERN` | `-e PATTERN` | Исключить файлы по паттерну | `-e "*.log"` |
| `--help` | `-h` | Показать справку | `bun index.ts -h` |

### Паттерны исключений (как в .gitignore)

```bash
# Примеры использования
bun index.ts -e "*.log"                    # Все .log файлы
bun index.ts -e "node_modules"             # Директория node_modules
bun index.ts -e "temp*"                    # Файлы, начинающиеся с temp
bun index.ts -e "*test*"                   # Файлы, содержащие test
bun index.ts -e "*.tmp" -e "*.bak"         # Несколько паттернов
bun index.ts ~/project -e ".git" -e "dist" # Комбинированный запуск
```

|---------|-------------------|----------|
| **↑** | Стрелка вверх | Переместить курсор вверх |
| **↓** | Стрелка вниз | Переместить курсор вниз |
| **→** или **Enter** | Стрелка вправо или Enter | Войти в директорию |

| **Пробел** | Пробел | Выбрать/снять директорию (рекурсивно) |

| **e** | **у** | Показать информацию об исключениях |

### Выход из программы

| Клавиша | Русская раскладка | Действие |
|---------|-------------------|----------|
| **q** | **й** | Корректный выход из программы |

## 🎯 Работа с выбором файлов

### Рекурсивный выбор директорий (Пробел)

**Поведение при нажатии Пробела на директории:**

#### Если директория НЕ выбрана

1. ✅ Добавляется сама директория в выбранные
2. ✅ Рекурсивно добавляются ВСЕ файлы внутри
3. ✅ Учитываются текущие настройки:
   - Паттерны исключений (если заданы)
   - Скрытые файлы (если выключены)
   - Фильтр по имени (если активен)

#### Если директория УЖЕ выбрана

1. ❌ Удаляется сама директория из выбранных
2. ❌ Рекурсивно удаляются ВСЕ файлы внутри

### Галочка ✓ возле директории означает

1. **Директория выбрана явно** (нажатием Пробел)
   **ИЛИ**
2. **Все файлы внутри директории выбраны**

### Режимы "Выбрать всё"

1. **`a` (ф)** - **Выбрать всё (с учетом исключений)**
   - Выбирает только файлы, НЕ попадающие под паттерны исключений
   - Учитывает текущий фильтр по имени
   - Игнорирует скрытые файлы, если они отключены

2. **`A` (Ф)** - **Выбрать всё (полностью)**
   - Выбирает ВСЕ файлы в текущей директории
   - Игнорирует исключения и фильтры
   - *Используйте с осторожностью в больших директориях!*

## 🔍 Режим фильтрации (клавиша `f` или `а`)

### Как работает

1. Нажмите `f` (или `а` в русской раскладке)
2. Вверху появится поле для ввода: `Фильтр: _`
3. Вводите текст для фильтрации имен файлов
4. **Enter** - применить фильтр
5. **Esc** - отменить фильтр

### Особенности

- Фильтрация происходит в реальном времени
- Учитывается регистр (нечувствителен)
- Применяется только к именам файлов, не к путям
- Сохраняется при переходе между директориями

### Расширенные возможности

### Конфигурация через YAML

Tree Explorer поддерживает конфигурацию через файл `config.yaml`. Создайте этот файл в корневой директории проекта:

```yaml
# Конфигурация Tree Explorer
defaultSavePath: /путь/для/сохранения
```

Доступные опции:
- `outputFile`: Файл для сохранения выбранных файлов в JSON формате. Если не указан, создается файл с уникальным именем в текущей директории.

### Просмотр выбранных файлов (клавиша `s` или `ы`)

Показывает структурированный список:

- 📁 Файлы группируются по директориям
- 🎯 Показываются иконки типов файлов
- ⚠️ Отмечаются исключенные файлы (если есть)
- 📊 Общее количество выбранных элементов

### Информация об исключениях (клавиша `e` или `у`)

Показывает:

- 📝 Все активные паттерны исключений
- 📚 Примеры использования паттернов
- 📊 Статистику по исключениям

### Поддержка разных терминалов

Программа автоматически определяет и использует:

- Размер терминала (столбцы и строки)
- Поддержку цветов (от 8 до 24-bit)
- Кодировку символов (UTF-8)

## ⚠️ Ограничения и известные особенности

### Поддерживаемые системы

- ✅ **Linux** (полная поддержка)
- ✅ **macOS** (полная поддержка)
- ❌ **Windows** (не поддерживается из-за различий в терминалах)

### Ограничения производительности

- ⚠️ **Большие директории** (10,000+ файлов) могут замедлить работу
- ⚠️ **Глубокие вложенности** влияют на скорость рекурсивного выбора
- ⚠️ **Сетевые файловые системы** могут работать медленнее

### Особенности работы

- ✅ **Символические ссылки** обрабатываются корректно
- ⚠️ **Жесткие ссылки** показываются как отдельные файлы
- ✅ **Права доступа** - файлы без прав чтения пропускаются
- ✅ **Специальные файлы** (пайпы, сокеты) показываются корректно

## 🆘 Поддержка и устранение проблем

### Частые проблемы и решения

#### Проблема: Не работают стрелки или горячие клавиши

**Решение:** Проверьте раскладку клавиатуры. Программа поддерживает обе раскладки, но некоторые терминалы могут требовать дополнительной настройки.

#### Проблема: Нет цветного вывода

**Решение:** Убедитесь что ваш терминал поддерживает ANSI colors:

```bash
echo -e "\\x1b[32mGreen\\x1b[0m"  # Должен показать зеленый текст
```

#### Проблема: Программа зависает

**Решение:** Нажмите `Ctrl+C` для выхода. Проверьте права доступа к файлам в текущей директории.

#### Проблема: Не отображаются русские буквы

**Решение:** Убедитесь что терминал использует UTF-8 кодировку:

```bash
echo $LANG  # Должно быть что-то вроде en_US.UTF-8 или ru_RU.UTF-8
```
