## Широкое использование PTYs в Bun

### 🎯 **Суть нововведения**

Bun добавил встроенный API для создания **псевдотерминалов (PTY)**, что позволяет запускать интерактивные программы (bash, vim, htop) так, будто они работают в реальном терминале.

### ✨ **Ключевые возможности**

1. **Интерактивность**: Дочерний процесс «видит» PTY как настоящий терминал (`process.stdout.isTTY === true`), что включает цветной вывод, движение курсора, интерактивные подсказки.
2. **Управление вводом/выводом**: Вы можете программно отправлять команды и читать вывод.
3. **Переназначение**: Один терминальный объект можно использовать для нескольких процессов.
4. **Обработка изменения размера**: Терминал можно динамически масштабировать при изменении размера окна.

### 📝 **Основные API и примеры**

#### **1. Базовое использование с `Bun.spawn()`**

Прикрепите PTY к любому дочернему процессу через опцию `terminal`:

```javascript
const proc = Bun.spawn(["bash"], {
  terminal: {
    cols: 80,                     // ширина
    rows: 24,                     // высота
    data(terminal, data) {        // обработка вывода
      process.stdout.write(data); // выводим в консоль

      // Автоматически отправляем команду при появлении приглашения
      if (data.includes("$")) {
        terminal.write("ls -la\n");
      }
    },
  },
});

await proc.exited;
proc.terminal.close(); // не забудьте закрыть
```

#### **2. Запуск полноценных интерактивных программ (например, Vim)**

```javascript
const proc = Bun.spawn(["vim", "file.txt"], {
  terminal: {
    cols: process.stdout.columns,
    rows: process.stdout.rows,
    data(terminal, data) {
      process.stdout.write(data); // показываем интерфейс Vim
    },
  },
});

// Динамическое изменение размера при масштабировании окна
process.stdout.on("resize", () => {
  proc.terminal.resize(process.stdout.columns, process.stdout.rows);
});

// Перенаправляем пользовательский ввод в Vim
process.stdin.setRawMode(true); // важен для спец.клавиш (Ctrl+C, стрелки)
for await (const chunk of process.stdin) {
  proc.terminal.write(chunk);
}

await proc.exited;
```

#### **3. Переиспользуемые терминалы (`Bun.Terminal`)**

Создайте отдельный терминальный объект для нескольких процессов:

```javascript
// `await using` автоматически закроет терминал
await using terminal = new Bun.Terminal({
  cols: 80,
  rows: 24,
  data(terminal, data) {
    process.stdout.write(data);
  },
});

// Используем один терминал для разных процессов
const proc1 = Bun.spawn(["echo", "Привет от первого процесса"], { terminal });
await proc1.exited;

const proc2 = Bun.spawn(["echo", "Второй процесс"], { terminal });
await proc2.exited;
// Терминал закроется сам благодаря `await using`
```

### ⚙️ **Методы управления `Bun.Terminal`**

* `.write(data)` – отправить данные (команды) в процесс
* `.resize(cols, rows)` – изменить размер PTY
* `.setRawMode(true/false)` – включить/выключить raw-режим для обработки спец.символов
* `.ref()` / `.unref()` – контролировать, будет ли терминал удерживать процесс активным
* `.close()` – явно закрыть терминал (происходит автоматически с `await using`)

### ⚠️ **Важное ограничение**

**PTY API работает только на POSIX-системах** (Linux, macOS). На Windows эта функциональность пока недоступна, но разработчики просят создавать issues, если она нужна.

### 🛠 **Типичные сценарии использования**

* Создание **интерфейсов командной строки (CLI)** с интерактивным вводом
* Встроенные **терминальные эмуляторы** в приложениях (например, веб-IDE)
* **Автоматизация скриптов**, которым нужен полноценный терминальный сеанс
* **Тестирование** интерактивных консольных программ

Эта функция делает Bun полноценным инструментом для создания сложных CLI-приложений и сред разработки с терминальной интеграцией.
